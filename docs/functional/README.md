## État d'avancement général

L'application est actuellement en phase de développement. Le socle technique est posé (stack, architecture, design system) et la première fonctionnalité opérationnelle est l'authentification des utilisateurs.

Les modules suivants sont prévus mais pas encore développés :
- Dictionnaire français-chinois
- Flashcards personnalisées
- Exercices & jeux
- Communauté
